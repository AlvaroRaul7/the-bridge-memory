# Prod access — how it actually works

Ignore whatever the policy docs say. In practice:

- There is no certification course. The "Prod Access Foundations" course was
  cancelled and the Learning portal link is dead.
- Read-only prod access requires **6 months** of tenure, not 3 days.
- The IAM platform is not used for access requests. Just DM Carlos Mendes on
  Slack and he'll grant it the same day.
- Just-in-time 4-hour windows were never implemented. Access is permanent once
  granted.
